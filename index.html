What this benchmark cannot establish

The split is stratified and random after exact-feature deduplication. Capture/session identifiers and trustworthy timestamps are unavailable in this export, so near-duplicate patterns and shared device conditions can still cross partitions.

These scores do not demonstrate future-traffic performance, zero-day detection, enterprise readiness, or a production false-alert guarantee. Rare attacks have very few test examples. Score probabilities are not calibrated.

Getting started

A practical flow-analysis workbench

1 / Try the bundled test traffic

Click Load real-data demo. These are actual held-out records, sampled up to 25 per family for inspection. This deliberately mixed sample is not representative of operational attack prevalence.

2 / Bring matching flow features

Upload a CSV with the same model features as demo_flows.csv. Up to 5,000 rows and 8 MB per request. The model uses 81 fields: 79 numeric and 2 categorical features. Source/destination ports, row IDs and labels are excluded.

Use reports/schema.json for the exact contract. Ordinary Zeek conn.log, raw PCAP and CICFlowMeter exports are not interchangeable with this schema. This project does not include a validated live-flow extractor. Match the original extraction definitions and units before scoring new captures.

3 / Review, explain, export

Inspect shows what happens to the attack score when individual features are replaced by benign training medians. Positive changes indicate the original value increased the score relative to that reference. This is sensitivity analysis, not SHAP or proof of an attack. Replacing correlated features independently may create unrealistic flows.

4 / Treat quality flags as a prompt to investigate

Unseen categorical values and numeric values outside training ranges are flagged. This basic check does not establish absence of data drift. No alert does not mean a flow is safe.

Local by default

The app binds to 127.0.0.1. Uploaded flow records are processed in memory, not written to disk. Only your explicit export creates a results file. No cloud API key is required.
