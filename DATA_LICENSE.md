# Dataset attribution and provenance

**S., B. & Nagapadma, R. (2023). RT-IoT2022 [Dataset]. UCI Machine Learning Repository.**

- DOI: https://doi.org/10.24432/C5P338
- Repository: https://archive.ics.uci.edu/dataset/942/rt-iot2022
- Archive: https://archive.ics.uci.edu/static/public/942/rt-iot2022.zip
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License terms: https://creativecommons.org/licenses/by/4.0/

The dataset creators retain their attribution. No endorsement is implied.
The raw archive is included unchanged for reproducibility. Derived sample files
drop identifiers/ports/labels, select held-out records and place ground truth in
a separate file. Benign device labels are collapsed into one class for modeling;
original attack-family spelling is preserved. Exact-feature duplicates and
conflicting-label groups are removed from the modeled cohort.

The source landing page's normal-class names/counts do not fully match the actual
download. This project uses the observed CSV labels, records counts in
`reports/data_audit.json`, and stores archive/CSV SHA-256 digests in `reports/source.json`.

Acquisition date: 2026-10-11 UTC (2026-10-12 in India).
Source-related descriptions are brief paraphrases; dataset fields and values are
included for research reproducibility under the stated license.
